# 현 세션 휴리 조직 구조 보정

이 문서는 2026-05-31 대화에서 사용자가 추가한 [[concepts/휴리|휴리]]의 조직 구조와 [[concepts/리미나리스 의회|리미나리스 의회]] 아래 차원술사 귀족 운영 방식의 대비를 정리한 출처 요약이다.

## 원문 요지

- 휴리의 구조는 중앙, 연구부, 전쟁부, 생산부로 나뉜다.
- 리미나리스는 의회 아래에서 각 [[concepts/차원술사 귀족|차원술사 귀족]]이 기업과 사회 재단을 운영하는 형태다.
- 반대로 휴리는 전체가 하나의 집단처럼 운영된다.

## 정본 반영 방향

- [[concepts/휴리 조직 구조]]를 별도 개념으로 두고, 휴리가 중앙, 연구부, 전쟁부, 생산부의 4분할 구조로 움직인다는 설정을 정리한다.
- [[concepts/휴리|휴리]] 본문에는 이 구조를 마법사령 핵심 프로젝트·군사·학술 집단이라는 기존 성격의 조직적 표현으로 반영한다.
- [[concepts/리미나리스 의회]]와 [[concepts/차원술사 귀족]]에는 리미나리스가 의회 아래 귀족별 기업·사회 재단 네트워크로 운영된다는 대비를 보강한다.
- 기능 해석상 연구부는 차원술·학술 연구, 전쟁부는 군사 행동, 생산부는 물자·마도구·산업 생산, 중앙은 전체 조율을 맡는 것으로 읽을 수 있다. 다만 각 부서의 정식 권한과 지휘 계통은 추가 검삭이 필요하다.

## 검삭 필요

- 중앙, 연구부, 전쟁부, 생산부의 정식 명칭.
- 네 부서가 표면 행정부인지, [[concepts/휴리 가주회의|휴리 가주회의]] 이너서클과 직접 연결된 실질 조직인지.
- 연구부, 전쟁부, 생산부의 장 또는 중역이 가주회의에 참여하는지.
- 생산부가 휴리 상회와 같은 대외 경제 조직을 포함하는지.
- 리미나리스의 기업과 사회 재단이 귀족 개인 소유인지, 가문 소유인지, 의회 산하 법인인지.
