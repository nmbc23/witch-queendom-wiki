# 카나데라 휴리

카나데라 휴리는 [[entities/jerae-hyuri|제라애 휴리]]의 명을 받드는 [[concepts/휴리|휴리]]의 실권자 중 하나이며, [[entities/irenia-hyuri-34|이레니아 휴리 34]]에 대한 직접 실행 명령을 받은 인물이다. 그러나 이레니아가 껄끄러워 일부러 피해다니며, 마지막에는 크게 망설이다가 이레니아에게 사실을 고백하고 도망치게 할 것이다.

## 확정 행적

- 제라애의 명을 받드는 휴리 실권자다.
- 이레니아에 대한 직접 실행 명령을 받은 자다.
- 이레니아가 껄끄러워 그냥 피해다닌다.
- 이레니아와 마주쳤다가 언젠가 명령을 실행해야 할까 봐 두려워한다.
- 마지막에는 굉장히 망설이다가 이레니아에게 고백한다.
- 고백 뒤 이레니아를 도망치게 할 것이다.

## 서사적 기능

카나데라는 명령의 집행자가 명령을 견디지 못하는 축이다. 그녀는 이레니아를 적극적으로 적대하기보다 피한다. 이 회피는 비겁함이면서도, 마주치면 제거 명령을 실행해야 할지 모른다는 두려움에서 나온다.

마지막의 고백은 제라애의 명령 체계를 깨는 순간이다. 카나데라는 휴리 실권자이면서도 이레니아에게 도망칠 시간을 주는 내부 배신자가 되고, 이레니아에게 휴리 내부 전체가 하나의 얼굴로만 움직이지 않는다는 사실을 보여준다.

## 관계

- [[entities/jerae-hyuri]]: 직접 실행 명령을 내린 현 휴리 가주.
- [[entities/suika-hyuri]]: 같은 제라애 명령 라인에 선 휴리 실권자. 스이카는 끝내 명을 실행한다.
- [[entities/irenia-hyuri-34]]: 직접 실행 명령의 대상이지만, 마지막에 사실을 고백하고 도망치게 하는 인물.
- [[concepts/휴리 가주회의 회의록]]: 이레니아 배척 논의와 제거 명령의 정치적 배경.

## 미확정

- 카나데라가 받은 직접 실행 명령의 구체 내용.
- 카나데라가 이레니아에게 고백하는 장면의 루트와 시점.
- 카나데라가 이레니아를 도망치게 한 뒤 어떤 처분을 받는지.
