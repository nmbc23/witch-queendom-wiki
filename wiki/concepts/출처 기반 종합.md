# 출처 기반 종합

출처 기반 종합은 단순히 그럴듯한 요약을 쓰는 것이 아니라, 어떤 원천이나 기존 위키 페이지에서 나온 내용인지 추적할 수 있게 정리하는 방식이다.

## 핵심 원칙

- 중요한 주장에는 관련 원천 문서나 위키 페이지를 연결한다.
- 추론으로 만든 내용은 확정 설정과 구분한다.
- 충돌하거나 미정인 설정은 지우지 말고 `미확정`으로 남긴다.

## 이 소설 위키에서의 용도

아세로리온의 트라우마, 에메랄드 타블렛, 크로니카의 흡혈 마술, 카마소 카밀라 사태처럼 여러 대화 조각에서 생긴 설정을 한 문서에서 이어붙일 때 사용한다.
