# 휴리 조직 구조

휴리 조직 구조는 [[concepts/휴리|휴리]]가 중앙, 연구부, 전쟁부, 생산부로 나뉘어 하나의 집단처럼 운영되는 구조다. 이 구조는 휴리가 단순한 차원술사 가문 연합이 아니라, [[entities/nerine|네리네 네에나리]]가 만든 마법사령의 대형 실행 집단이라는 점을 드러낸다.

## 네 부서

- 중앙: 휴리 전체의 방향, 조율, 행정 중심으로 해석되는 축.
- 연구부: 차원술, 학술, 마법사령 주요 프로젝트 연구를 담당하는 축.
- 전쟁부: 휴리의 군사 행동과 대외 전투력을 담당하는 축.
- 생산부: 물자, 마도구, 산업 생산, 프로젝트 산출물을 담당하는 축.

이 기능 배분은 부서명에서 읽히는 합리적 해석이다. 정식 권한, 부서장, 산하 조직, 예산과 명령 체계는 아직 확정되지 않았다.

## 하나의 집단처럼 운영되는 휴리

휴리는 전체가 하나의 집단처럼 운영된다. 네 부서는 서로 독립한 귀족 조직이라기보다, 하나의 휴리 집단 안에서 역할을 나눈 기능부에 가깝다.

이 때문에 휴리는 [[concepts/차원술사 귀족|차원술사 귀족]]들이 모여 정치적 조율을 하는 리미나리스보다 더 통합적인 조직감을 가진다. 휴리 내부에도 [[concepts/휴리 가주회의|휴리 가주회의]]와 표면 행정부, 네리네가 투입한 인재와 오래된 집안의 갈등이 있지만, 대외적으로는 혈족 전체가 하나의 실행 기관처럼 보인다.

## 리미나리스와의 대비

[[concepts/리미나리스 의회|리미나리스]]는 의회 아래에서 각 차원술사 귀족이 기업과 사회 재단을 운영하는 형태다. 즉 리미나리스의 사회는 귀족별 법인, 재단, 후원 네트워크가 의회 정치 아래 병렬로 놓인 구조에 가깝다.

반대로 휴리는 중앙, 연구부, 전쟁부, 생산부라는 내부 기능 구획을 통해 하나의 큰 조직으로 움직인다. 리미나리스가 귀족들의 느슨한 정치·경제 생태계라면, 휴리는 혈족 단위로 통합된 프로젝트 집단이다.

이 대비는 두 집단의 성격 차이를 선명하게 만든다. 리미나리스는 개방성과 귀족별 자율성 때문에 역동적이지만 첩보 오염에 취약하고, 휴리는 폐쇄성과 통합성 때문에 답답하지만 보안과 실행력이 강하다.

## 검삭 필요

- 중앙, 연구부, 전쟁부, 생산부의 정식 명칭과 부서장.
- 네 부서가 표면 행정부인지, 휴리 가주회의와 직접 이어진 실질 조직인지.
- 생산부가 [[entities/jerae-hyuri|제라애 휴리]]의 휴리 상회 같은 대외 경제 조직을 포함하는지.
- 연구부와 죽음의 계곡 휴리 비밀 차원 연구소의 관계.
- 전쟁부가 리미나리스 견제, 스테리 구출, 차원 방랑자 복원계획 중 어디까지 직접 담당하는지.
