# Wiki Schema v2.1

이 위키는 `raw/`의 원천 자료를 근거로 유지되는 소설 설정 위키다.

제1원칙: **한 사실은 한 곳에.** 서술의 정본은 개별 페이지, 목록은 자동 생성 index, 순서는 연표, 관계 서술은 관계 페이지가 담당한다.
제2원칙: **애매하면 만들지 말고 물어라.** 판정은 저자의 몫이다. 아래 생성 게이트를 따른다.

## 디렉토리 역할

세계 층위 (작중 사실):
- `인물/` 개별 인물·존재 · `세력/` 가문·조직·기구·파벌 · `장소/` 지역·시설·차원 · `법칙/` 원리·체계·제도·신분·담론 · `사물/` 아티팩트·장치·기록물 · `사건/` 일어난 일과 진행 중인 작전·계획 · `관계/` 둘 이상에 걸친 관계·분쟁·상호 인식

서사 층위 (이야기에 대한 사실):
- `파트/` 파트 입구 · `종합/` 아크 서사·연표·톤 분석 (**목록형 카탈로그 금지** — 목록은 index의 일)

작업 층위:
- `소스/` 원문 단위 소스 페이지만 (**세션 보정용 소스 페이지 생성 금지**) · `질문/` 보존할 질문-답변 · `메타/` 위키·제작 자료 · `템플릿/` 새 페이지 원형 · `뷰/` Obsidian Bases 계산 뷰 (Obsidian 1.9+)
- `index.md` 자동 생성 목차 (손편집 금지, `python tools/generate_index.py`) · `log.md` append 전용 작업 기록 · `미결.md` 판정 대기 큐 · `schema.md` 이 문서

교차 속성(part, 시점, 소속, status)은 폴더가 아니라 frontmatter 필드로만 표현한다. 세계 폴더 아래 하위 폴더를 만들지 않는다.

## 생성 게이트 — 새 페이지가 생기는 유일한 경로

새 개체 이름이 나타나면 세 밴드 중 하나로 처리한다.

**자동 생성** (전부 충족 시에만):
1. 정식 명칭이 원문에서 확정됨 (이름 파편·이명 추정이 아님)
2. 독립된 확정 사실이 2개 이상 서술 가능함
3. 기존 페이지와 동일 대상일 합리적 후보가 없음
→ `템플릿/`에서 인스턴스화해 생성한다.

**자동 수납** (하나라도 해당 시):
- 이름 파편·축약·이명으로 보이는 유력 후보 페이지가 있음 → 그 페이지 aliases에 추가, 미결.md에 판정 요청 1건 등록. **페이지를 만들지 않는다.**
- 확정 사실이 1개 이하 → 가장 가까운 상위 페이지의 섹션으로 서술. 섹션은 제3의 참조가 생기거나 비대해질 때 페이지로 승격한다(3의 법칙).

**질문 밴드** (그 사이의 모든 경우):
- 현재 작업을 막는 애매함 → 저자에게 즉시 판정 패킷으로 질문
- 막지 않는 애매함 → 미결.md에 판정 패킷으로 등록하고 진행

판정 패킷 형식 (질문과 미결 항목 공통):
```
### 항목명 — 한 줄 요지
- 발견: 어디서 (raw 경로)
- 유력 후보: [[링크]] — 근거 한 줄
- A. 선택지 / B. 선택지 / C. 보류
- 판정:
```
후보 대조는 에이전트가 끝내서 제시하고, 저자는 판정만 한다.

## 판정의 집행 — 저자의 답도 보정 1건이다

미결.md의 `판정:` 줄이 채워졌거나 세션 중 판정을 받으면:
1. 판정 요지를 `raw/sessions/YYYY-MM-DD-판정.md`에 기록
2. 집행: 병합·별칭 이전·링크 치환·생성·이동
3. **"별개 확정" 판정은 양쪽 frontmatter에 `관계: X와 별개 (YYYY-MM-DD 판정)`으로 명시** — 안 하면 다음 세션에 같은 질문이 반복된다
4. 미결 항목을 `## 처리됨`으로 이동, log에 1항목

## 병합 절차 (5단계)

1. 원본 페이지의 고유 서술을 대상 페이지로 이관
2. 원본의 aliases 전부를 대상 aliases로 이전 (원본 제목 포함)
3. 원본을 가리키던 링크 전역 치환
4. 원본 파일을 `raw/archive/`로 이동
5. `python tools/generate_index.py` 재실행, log 1항목

## 미상 명명 규약

미확정 개체가 부득이 페이지를 받아야 하면(자동 수납 불가, 판정 보류 중 참조 필요) 제목을 `미상 ○○` 또는 관계형(`네리네의 보호자`)으로 짓는다. 정식 명칭이 확정되면 개명하고 옛 제목은 aliases로.

## 관계 페이지

둘 이상의 인물·세력에 걸친 큰 관계(분쟁·동맹·상호 인식)는 어느 한쪽 페이지에 몰아 쓰지 않고 `관계/`에 독립 페이지로 두며, 당사자 페이지들은 링크만 건다. 같은 관계 서술이 양쪽 페이지에 복사되는 것을 금지한다.

## 보정(ingest) 절차

1. 세션 원문/요지를 `raw/sessions/YYYY-MM-DD-주제.md`로 기록 (위키 소스 페이지 생성 금지)
2. 새 개체는 생성 게이트를 통과시킨다
3. 영향받는 페이지 본문 직접 수정, frontmatter `sources:`에 raw 경로 추가
4. log 1항목. 페이지 생성·삭제·개명이 있었을 때만 index 재생성
표준 비용 = raw 1 + 페이지 1~3 수정 + 로그 1항목. 카탈로그·목차 수동 갱신 단계는 없다. [[종합/소설 상세 사건 연표]]는 사건의 존재·순서가 실제로 바뀔 때만 수정.

## 명명·링크·frontmatter

- 파일명은 한글 정식 명칭. 공백 허용, `/ \ : * ? " < > |` 및 꼬리 공백·점 금지. 옛 이름은 aliases에.
- 페이지 링크는 폴더 경로 포함: `[[인물/아이카 데스모네|아이카]]`. raw 인용은 위키링크 없이 평문/백틱 경로.
- 원문에 직접 없는 종합 서술은 "추론" 표기.
- type은 폴더명과 일치(인물·세력·장소·법칙·사물·사건·관계·종합·소스·메타·파트). status: draft | reviewed | stale | generated. 그 외 updated, aliases, part, tags, sources, (사건) 시점, (관계) 당사자.

## 인코딩

- 모든 markdown은 UTF-8. Windows PowerShell은 `-Encoding UTF8` 명시.
- 이미지·자산 링크는 `assets/` 파일시스템으로 검증하며 없는 페이지로 취급하지 않는다.

## 점검(lint)

- 깨진 위키링크 (페이지·자산 구분)
- 게이트 위반: 확정 사실 1개 이하의 신규 페이지, 후보 대조 없는 이름 파편 페이지
- `소스/`의 세션 보정 페이지, `종합/`의 목록형 카탈로그, 세계 폴더의 하위 폴더
- "별개 확정" 판정의 frontmatter 미기재 (질문 반복의 원인)
- 페이지 생성·삭제 후 index 재생성 누락
